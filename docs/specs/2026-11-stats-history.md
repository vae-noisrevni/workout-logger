# Спека: статистика, избранное, превью и экспорт тренировки, комментарии к упражнениям

Дата: 2026-11-01. Калькулятор подходов исключён из объёма (решение владельца).

## Решения

| Тема | Решение |
|---|---|
| Где статистика | Новый 4-й таб «Статистика» |
| Избранное | Флаг `favorite` у упражнения, звезда в справочнике и в форме. Избранные — наверху списков (справочник и лента на экране тренировки), внутри групп по алфавиту. Флаг идёт в экспорт/импорт справочника |
| Топ-показатель | weighted → макс. вес (с повторами этого подхода и датой); bodyweight и assisted → макс. повторы в подходе |
| Помесячно | Только «этот месяц vs прошлый»: кол-во тренировок + лучший результат по каждому избранному, с дельтой |
| Клон подхода | «Добавить подход» копирует повторы и вес последнего подхода. Первый подход упражнения — как раньше (10 × 0) |
| Превью | Тап по карточке в истории → отдельный экран (route) только для чтения. В шапке: «Экспорт», «Редактировать». Удаление — свайпом в списке, как сейчас |
| Экспорт одной тренировки | CSV / JSON (тот же формат, что у истории, импортируется обратно) + читаемый текст через системное «Поделиться». Текстовый экспорт — только для одной тренировки; импорт текста не делаем |
| Коммент к упражнению | Поле в шторке подходов. Над полем — серый коммент из прошлой тренировки с этим упражнением. Показывается в карточке на экране тренировки и в превью; идёт в экспорт/импорт истории |
| Git | По коммиту на тикет в `main`, без пуша |

## Тикеты

### T1. Модель данных: favorite и comment
- Миграции: `exercises.favorite INTEGER NOT NULL DEFAULT 0`, `workout_exercises.comment TEXT NOT NULL DEFAULT ''` (по образцу `migrateExercisesColor`).
- Типы: `Exercise.favorite: boolean`, `WorkoutExercise.comment`, `DraftExercise.comment?` (черновики в AsyncStorage без поля должны читаться), `CreateWorkoutInput`/`ImportedWorkout` — `comment` у упражнения.
- Репозитории читают/пишут новые поля; сортировка упражнений `favorite DESC, name`.
- Черновик: `loadWorkout` переносит коммент, сохранение тренировки передаёт его в БД.

### T2. Клон последнего подхода
- `addSet` в `useWorkoutDraft` создаёт подход с reps/weight последнего; если подходов нет — 10 × 0.

### T3. Избранное в UI
- Звезда-переключатель в `ExerciseRow` (тап по звезде не открывает редактирование) и переключатель в `ExerciseForm`.
- Экспорт справочника: колонка/поле `favorite`; импорт — необязательное поле (`true/false/1/0`, по умолчанию false). Обновить `docs/formats`.

### T4. Комментарий к упражнению в тренировке
- `setComment(exerciseId, text)` в черновике; многострочное поле в `SetsSheet` под подходами.
- Подсказка: последний непустой коммент к этому упражнению из истории (при редактировании — исключая саму редактируемую тренировку).
- Коммент виден в `WorkoutCard`.
- Экспорт/импорт истории: JSON — `exercises[].comment`; CSV — колонка `exercise_comment` (повторяется в каждой строке подхода, при импорте берётся первая непустая). Обновить `docs/formats`.

### T5. Экран превью тренировки
- Route `src/app/workout/[id].tsx` (Stack с заголовком). Данные — `getWorkoutById`, обновление по `workoutsRevision`; если тренировка удалена — пустое состояние.
- Содержимое: название, дата, коммент тренировки, сводка (упражнений/подходов/тоннаж), упражнения с подходами и комментами.
- «Редактировать» — существующий флоу (с подтверждением замены черновика) → переход на таб «Тренировка».
- В истории тап по карточке открывает превью; иконка в карточке меняется на chevron.

### T6. Экспорт одной тренировки
- Кнопка в шапке превью → диалог: Текст / CSV / JSON / Отмена.
- Текст через `Share.share` из react-native, формат:
  ```
  Тренировка от 1 ноября — 1 ноября 2026
  Комментарий тренировки

  Жим лёжа
  1. 10 × 60 кг
  2. 8 × 65 кг
  💬 коммент к упражнению
  ```
  Для bodyweight — «10 повт.».
- CSV/JSON — через существующие `workoutsToCsv/Json` с одной тренировкой, имя файла `workout-<дата>-<id>.<ext>`.

### T7. Таб «Статистика»
- Новый таб `stats` (иконка `stats-chart-outline`), данные пересчитываются по `workoutsRevision` и `exercisesRevision`.
- Блок «Тренировок в месяц»: текущий месяц vs прошлый, дельта.
- Блок «Избранные»: по каждому избранному — рекорд за всё время (значение + дата), лучший результат этого месяца vs прошлого с дельтой (кг или повторы). Пусто → подсказка отметить упражнения звездой.
- Расчёт в чистых функциях `src/utils/stats.ts` по массиву `Workout[]`.
